# Assets

This directory contains visual assets for CalcQuest press and documentation purposes.

## Directory Structure

```
assets/
├── icon.png              # App icon
├── banner.jpg            # Promotional banner
└── gameplay/
    ├── level-example-1.png   # Example level screenshot
    └── qr-sharing-demo.png   # QR sharing feature screenshot
```

## Placeholder Notice

The files referenced above should be added by the developer. This README serves as a guide for the expected structure.

## Asset Specifications

### icon.png
- Purpose: App icon for press and promotional use
- Recommended size: 512x512 px or higher
- Format: PNG with transparency

### banner.jpg
- Purpose: Promotional banner for store listings or social media
- Recommended size: 1200x630 px (social media standard)
- Format: JPEG

### gameplay/
- Purpose: Screenshots demonstrating gameplay and features
- Recommended size: Device resolution or 1080p equivalent
- Format: PNG preferred
