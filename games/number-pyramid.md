# How to play Number Pyramid

Number Pyramid is a number puzzle where every cell equals the sum of the two cells directly below it; you fill in the missing cells by adding upward and subtracting downward. Number Pyramid is one of the 20+ puzzle games in CalcQuest, the free brain puzzle game for Android, iOS and the web.

## Rules of Number Pyramid

1. Every cell equals the sum of the two cells directly beneath it.
2. Fill the missing cells so every row obeys the rule, up to the top.
3. Every cell has exactly one correct answer.

## Tips for Number Pyramid

- Add pairs on the bottom row to fill the row above.
- If an upper cell is known but one cell below it is missing, subtract: missing = upper − known neighbour.
- You need both cells of a pair before you can fill the cell above them.
