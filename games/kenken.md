# How to play KenKen

KenKen is a math logic puzzle: fill an N×N grid with the numbers 1 to N so that no number repeats in any row or column, and the numbers in each outlined cage combine with the cage's operation to make its target. ## Rules of KenKen

1. Fill the grid with the numbers 1 to N, where N is the grid size. A 4×4 grid uses 1 to 4.
2. Each number appears exactly once in every row and every column.
3. Cells are grouped into cages, each with a target and an operation (+, −, ×, ÷). The numbers in a cage must combine with that operation to make the target.
4. Numbers may repeat inside a cage, as long as they do not repeat in a row or column.

## Tips for KenKen

- A one-cell cage is a free answer: the target is the number.
- For two-cell − and ÷ cages, only a few pairs work. List them, then eliminate with the row and column rules.
- If a number can only go in one cell of a row or column, place it, even before its cage is solved.
