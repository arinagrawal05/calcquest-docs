# How to play Mini Sudoku

Mini Sudoku is a 6×6 version of Sudoku: fill the grid with the numbers 1 to 6 so that every row, every column and every 2×3 box contains each number exactly once. Mini Sudoku is one of the 20+ puzzle games in CalcQuest, the free brain puzzle game for Android, iOS and the web.

## Rules of Mini Sudoku

1. Fill every empty cell with a number from 1 to 6.
2. Each row contains 1 to 6 exactly once.
3. Each column contains 1 to 6 exactly once.
4. Each 2×3 box (outlined in bold) contains 1 to 6 exactly once.
5. Pre-filled numbers are clues and cannot be changed.

## Tips for Mini Sudoku

- Look for a row, column or box with one empty cell: the missing number goes there.
- If a number fits in only one cell of a row, column or box, place it.
- Stuck? Find a cell where only one number survives its row, column and box together.
