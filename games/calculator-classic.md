# How to play Calculator Classic

Calculator Classic is the original CalcQuest game: you turn a starting number into a target number using a calculator whose buttons and number of presses are limited. It has 350+ handcrafted levels, each designed by hand. Calculator Classic is one of the 20+ puzzle games in CalcQuest, the free brain puzzle game for Android, iOS and the web.

## Rules of Calculator Classic

1. Each level gives you a starting number, a goal number and a set of calculator buttons.
2. You have a limited number of moves. Reach the goal before you run out.
3. Buttons go beyond + and −: special functions such as Reverse, Store and Delete change digits in surprising ways.

## Tips for Calculator Classic

- Work backwards from the goal to see which operation could have produced it.
- Count your moves before you start. If a route needs more presses than you have, look for a shortcut button.
- Special buttons such as Reverse often hold the "aha" moment of a level.

## 350+ handcrafted levels

Calculator Classic is where CalcQuest began in September 2024. It launched with 135 handmade levels, and 250 more followed. Every level was designed and solved by hand, so each one has an intended "aha" route. Calculator Classic also has its own five-level daily set and an endless mode. The story of how it grew into a 20+ game collection is in [From calculator game to brain puzzles](../dev-journey/from-calculator-game-to-brain-puzzles.md).

## Playing Calculator Classic in CalcQuest

Open Calculator Classic from the Games tab, under Math. Play the handcrafted levels in order, try the five-level daily set, or switch to Endless for fresh puzzles without limit.

Get CalcQuest on [Google Play](https://play.google.com/store/apps/details?id=com.calcquest.calculatorgame) or the [App Store](https://apps.apple.com/app/id6757161847).
