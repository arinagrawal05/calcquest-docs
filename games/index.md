# CalcQuest puzzle games

CalcQuest has 20+ top-rated puzzle games in four categories: Logic, Puzzle, Math and Memory. Every game has a built-in tutorial and can be played on its own in Timed or Endless mode, and the games come together in the Journey, the daily challenge and duels. This page lists every game with a one-line summary; each links to its full rules and tips.

## Logic games

| Game | What you do | Web |
|---|---|---|
| [Queens](queens.md) | Logic puzzle where you place exactly one queen in every coloured region of the board, so that no two queens share a row, a column, or touch, even diagonally | [Play](https://calcquest.app/queens) |
| [Tango](tango.md) | Logic puzzle where you fill a grid with suns and moons so that every row and column has equal numbers of each, never three alike in a row, and every = and × sign between cells is respected | [Play](https://calcquest.app/tango) |
| [Binairo](binairo.md) | Logic puzzle where you fill a grid with 0s and 1s so that every row and column has equal numbers of each, no three identical digits sit in a row, and no two rows or columns are the same | [Play](https://calcquest.app/binairo) |
| [Minesweeper](minesweeper.md) | Logic game where you uncover every safe cell on a board without touching a hidden mine, using numbers that tell you how many mines touch each cell | [Play](https://calcquest.app/minesweeper) |
| [Number Alchemy](number-alchemy.md) | Number puzzle where you combine a set of given numbers with +, −, × and ÷ to reach a target exactly, using each number at most once | App |

## Which game should I start with?

- **New to logic puzzles:** Mini Sudoku or Tango. The rules fit in one sentence.
- **Already play LinkedIn games:** Queens, Tango and Mini Sudoku, with unlimited boards.
- **Like numbers:** KenKen, Number Pyramid or Calculator Classic.
- **Want a quick, fast game:** Quick Calculation or Math Grid.
- **Want to train memory:** Flashback or Simon Sequence.

Nine of these games play free in a browser. See [Play on the web](../gameplay/play-on-the-web.md).
