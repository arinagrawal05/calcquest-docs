# Difficulty in CalcQuest

Every CalcQuest puzzle game offers three difficulties, Easy, Medium and Hard, and difficulty also rises every few rounds inside a session. New players start gently, and the game gets harder as you get better, so the puzzles stay challenging without becoming frustrating.

## The three levels

| Difficulty | Who it suits | What changes |
|---|---|---|
| Easy | New players, younger players, warming up | Smaller boards, more given clues, simpler numbers |
| Medium | Regular players | Standard boards and clue counts |
| Hard | Experienced puzzlers | Larger boards, fewer clues, bigger numbers, longer patterns |

What "harder" means depends on the game. In Mini Sudoku or Binairo, fewer cells are filled in at the start. In Minesweeper there are more mines. In the math games the numbers grow and the operations get more varied. In memory games the patterns are longer.

## Difficulty inside a session

In Timed and Endless play, difficulty steps up every 5 rounds. A long run therefore keeps pushing you, while the first rounds stay approachable.

## Difficulty in each mode

| Mode | How difficulty is set |
|---|---|
| Timed and Endless | You choose Easy, Medium or Hard in the game's sheet |
| Journey | Set by the level; later chapters ask more |
| Daily challenge | Set for the day, the same for everyone |
| Duels | The challenger's choice; the friend plays the same board |
| Calculator Classic | Each handcrafted level is tuned by hand, and the curve rises across the worlds |

## Fair puzzles at every level

Harder never means unfair. The 350+ handcrafted Calculator Classic levels were each designed and tested by hand, and the logic puzzles are generated so a board can be solved by reasoning rather than guessing. Tutorials and hints help when you are stuck.
