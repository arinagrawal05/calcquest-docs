# CalcQuest game modes

CalcQuest has six ways to play: the Journey (the main mode), the daily challenge, friend duels, Timed and Endless play for any single game, and Calculator Classic, the original handcrafted level campaign. Every mode uses the same 20+ puzzle games, so what you learn in one carries over to the others.

## The modes at a glance

| Mode | Clock | Ends when | What it counts for |
|---|---|---|---|
| [Journey](journey.md) | None | Each puzzle in the level is solved | Map progress, XP, gems, chests, trophies |
| [Daily challenge](daily-challenge.md) | Stopwatch | All four daily games are done | The daily leaderboard (best total time) |
| [Duels](duels.md) | Stopwatch | You solve the board | Beating a friend; duel wins and win streaks |
| Timed | Countdown | Time runs out | High score, leaderboards, XP |
| Endless | None | You decide to stop | XP, relaxed practice |
| [Calculator Classic](../games/calculator-classic.md) | None | Move limit reached or target hit | 350+ handcrafted levels |

## Journey

The main mode. A map of chapters with 10 levels each; every level is a short run of different puzzles, so one level can mix a logic grid, a quick sum and a memory pattern. See [The Journey](journey.md).

## Daily challenge

Four games, the same for everyone that day, played against a stopwatch. One attempt per day, and your total time goes on the daily leaderboard. See [Daily challenge](daily-challenge.md).

## Duels

Play a seeded board, then send the same board to a friend. Each of you plays in your own time and the fastest time wins. See [Friend duels](duels.md).

## Timed

Pick any game from the Games tab and choose Timed. You race a countdown to score as many points as you can; quick-fire games such as Quick Calculation add time for each correct answer. Your best score goes on the game's leaderboard.

## Endless

Choose Endless for no clock and no limit. It suits practice, learning a new game, or winding down. Endless play still earns XP.

## Calculator Classic

The game CalcQuest started with: reach a target number with a limited number of calculator presses. Calculator Classic holds the 350+ handcrafted levels, and also has its own daily set and an endless mode. See [Calculator Classic](../games/calculator-classic.md).

## Tutorials

The first time you open a game, a short tutorial teaches its rules by letting you play one round. The rules stay available from the game's details sheet. Every game's rules are also in these docs under [All puzzle games](../games/index.md).

## Difficulty

Every mode that lets you choose offers Easy, Medium and Hard, and difficulty rises every few rounds inside a session. See [Difficulty](difficulty.md).
