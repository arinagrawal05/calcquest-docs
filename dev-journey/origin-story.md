# The CalcQuest origin story

CalcQuest began as a side project in Arin Agrawal's first semester of college. He built the first version in two weeks, a calculator puzzle game with 135 handmade levels, and released it on Google Play on 3 September 2024. Two years later it is a brain puzzle game with 20+ top-rated puzzle games, 350+ handcrafted levels and 25K+ players in 150+ countries, still made by one person.

## The spark

The first idea was simple: a calculator is a tool for getting answers, but what if getting to the answer was the game? In the first CalcQuest you started from one number and had to reach a target using a calculator with only a few buttons and a limited number of presses. Some buttons did surprising things, such as reversing the digits. Each level had an "aha" route waiting to be found.

That game still lives in CalcQuest as [Calculator Classic](../games/calculator-classic.md).

## Two weeks to launch

Arin, a Flutter developer since 2023, built the first version in about two weeks and released it on 3 September 2024. It launched with 135 handmade levels, each designed and solved by hand.

## The churn problem

Players loved the levels, then binged through all of them, finished the game and uninstalled it. To keep them, Arin added 250 more handcrafted levels, bringing the total past 350. The result was the same: dedicated players finished the new levels and left again.

A fixed number of levels, however good, would never be enough for the most engaged players.

## The first pivot: endless puzzles

The answer was to add puzzles that never run out. CalcQuest introduced generated puzzles with endless modes, and retention changed sharply: players now had something new every day. Over 2025 and 2026, more and more puzzle games joined: number and memory games first, then logic puzzles such as Queens, Tango, KenKen, Shikaku, Nonogram and Mini Sudoku.

## The second pivot: a brain puzzle game

By 2026 CalcQuest was no longer a calculator game with extras; it was a collection of 20+ puzzle games. In version 2.2 (November 2026) the app was rebuilt around that: the [Journey](../gameplay/journey.md) became the main mode, with levels that mix games, alongside the [daily challenge](../gameplay/daily-challenge.md), [friend duels](../gameplay/duels.md), [guest play](../gameplay/guest-play.md), [CalcQuest Premium](../premium.md) and the [streak reward program](../campaigns/streak-rewards.md). The full story is in [From calculator game to brain puzzles](from-calculator-game-to-brain-puzzles.md).

## No marketing budget

CalcQuest has never paid for advertising. It grew by word of mouth, building in public on X, and a game people wanted to show their friends and families. It reached 25K+ players in 150+ countries that way.
