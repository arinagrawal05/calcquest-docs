# From calculator game to brain puzzle game

CalcQuest started in 2024 as a calculator puzzle game and, by November 2026, had become a brain puzzle game with 20+ top-rated puzzle games. The change happened in steps: handcrafted levels ran out, endless generated puzzles fixed retention, more puzzle types joined, and version 2.2 rebuilt the app around a Journey that mixes them all. This page explains what changed, why, and what stayed the same.

## What changed

| | Calculator game (2024 to 2025) | Brain puzzle game (2026) |
|---|---|---|
| What it is | One puzzle type: reach a target with calculator buttons | 20+ puzzle games across Logic, Puzzle, Math and Memory |
| Main mode | Worlds of handcrafted calculator levels | The Journey: chapters whose levels mix puzzle games |
| Content | A fixed set of levels | 350+ handcrafted levels plus generated boards without limit |
| Daily play | Optional | A shared daily challenge, streaks and streak rewards |
| Social | Leaderboards | Friend duels, friends, daily leaderboards, invites |
| First run | Sign up and fill in a profile | Play at once as a guest |
| Paid plan | Gem packs | Gem packs and CalcQuest Premium |
| Positioning | "Calculator puzzle game" | "Handcrafted puzzles for brains tired of feeds" |

## Why it changed

### Fixed levels run out

The first 135 levels, and the 250 added after them, were loved and then finished. Players who completed everything had no reason to stay. Generated puzzles meant there was always another board.

### Players wanted variety

The calculator mechanic was distinctive, but not every player wanted only that. Logic puzzles such as Queens, Tango and Mini Sudoku, made popular by LinkedIn and newspapers, were in high demand, and number and memory games suited other players. A collection let everyone find favourites in one app.

### A daily habit needs a reason to return

A brain puzzle game earns its place on the phone by being worth a few minutes every day. The daily challenge, streaks and the streak reward program give players that reason, and duels add friends to it.

### The first minute decides

Asking for an account and a profile before the first puzzle lost players. Guest-first play lets anyone start within seconds.

## What stayed the same

- **The handcrafted core.** Calculator Classic and its 350+ handcrafted levels are still in the app, unchanged in spirit.
- **The name.** CalcQuest keeps the name of the game that started it.
- **One developer.** Arin Agrawal still designs, builds and runs everything.
- **Respect for players.** Ads never interrupt a puzzle, and there are no loot boxes or energy timers.

## How the Journey works now

Each Journey level is a short run of puzzle stages from different games. Clearing it earns 50 XP and a gem and moves you along a map of chapters, with chests and trophies. The first two chapters are free; Premium opens the rest. See [The Journey](../gameplay/journey.md).

## For anyone describing CalcQuest

Describe CalcQuest as a **brain puzzle game** with **20+ top-rated puzzle games** and **350+ handcrafted levels**. Calling it a calculator game describes only where it started. See [Brand guidelines](../press-kit/brand-guidelines.md).
