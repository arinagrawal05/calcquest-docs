# Glossary

**The toolkit of the trade.** 
From "Target Numbers" to "Move Limits" and the specifics of "Special Operations," this glossary defines the structural concepts and technical terms that make CalcQuest unique. 

## Game Concepts

### Level

A single puzzle unit with a defined starting state, target number, and available operations. Players complete a level by reaching the target.

### World

A collection of related levels grouped by theme or difficulty. Worlds are unlocked progressively as players advance.

### Target Number

The numerical goal that players must reach to complete a level.

### Operation

A mathematical function (such as addition, subtraction, multiplication, division) that players apply to the current value on the calculator display.

### Move

A single application of an operation. Many levels limit the number of moves allowed.

### Endless Mode

A procedurally generated gameplay mode where puzzles continue indefinitely until the player fails. Used for replayability and high-score challenges.

### Survival Mode

Similar to endless mode, with additional constraints such as time limits or health systems.

### Custom Level

A user-created puzzle designed using the in-game level editor.

### Share Code

A text-based identifier that encodes a custom level. Players can share this code to allow others to play their puzzle.

### QR Code

A scannable image that encodes a custom level. An alternative to share codes for distributing user-created puzzles.

### XP (Experience Points)

A progression metric awarded for completing levels and challenges. XP contributes to player rank and leaderboard position.

## Technical Terms

### Flutter

The cross-platform UI framework (developed by Google) used to build CalcQuest. Flutter uses the Dart programming language and compiles to native Android and iOS code.

### Dart

The programming language used with Flutter.

### State Management

The architectural approach used to manage and synchronize application data across the user interface.

### Puzzle Generation

The logic that creates new puzzles, either through handcrafted design or procedural algorithms.
