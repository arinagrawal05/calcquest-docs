## 🌟 What is CalcQuest?

**CalcQuest** is a solo indie success story created by **Arin Agrawal**, transforming mental math into an addictive, elegant puzzle experience. Instead of repetitive drill flashcards, CalcQuest turns arithmetic into a creative playground centered around a simulated calculator interface.

Players start with an initial display number and must manipulate it to reach an exact target value using a restricted keypad (specific operators, number insertions, transformations, and reversals) within a strict move budget. What starts as straightforward arithmetic rapidly evolves into deep deductive logic and problem-solving.

Beyond its hero calculator mechanic, CalcQuest has grown into a **comprehensive 22-game cognitive puzzle suite** across five distinct mental disciplines—all delivered through an ethical, zero-forced-ads design philosophy.

## 🛠️ Tech Stack & Engineering Highlights

CalcQuest is built from the ground up as a high-performance cross-platform application:

- **Frontend Core:** Built with **Flutter & Dart** for native 60 FPS performance across Android, iOS, and Web.
- **State Management & DI:** Powered by **GetX** for predictable reactivity and decoupled dependency injection.
- **Type-Safe Routing:** Driven by **`go_router`** for deep linking and modular page navigation.
- **Cloud Infrastructure:** Powered by **Firebase** (Authentication, Cloud Firestore, Cloud Messaging, Crashlytics, Remote Config).
- **Monetization & In-App Purchases:** Managed via **RevenueCat** for seamless subscription and gem store entitlement tracking.
- **Analytics & Telemetry:** **Mixpanel** and **Firebase Analytics** for privacy-compliant user progression insights.
- **Platform Game Services:** Native integration with **Google Play Games Services** and **Apple Game Center**.
